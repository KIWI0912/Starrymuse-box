# StarryMuse Box 🌟

> An interactive idol simulation game built with React.
> 一款基于 React 构建的偶像箱庭模拟游戏。

---

## ⚡ Quick Start / 快速启动

```bash
git clone https://github.com/KIWI0912/starrymuse-box.git && cd starrymuse-box && npm install && npm run dev
```

一行命令，克隆 + 安装 + 启动，完成。

## Features / 功能特色

- 💬 Character chat system / 角色对话系统
- 📅 Daily schedule & activity choices / 每日日程与活动选择
- 🎒 Inventory and item collection / 道具收集与背包系统
- 📖 Diary system / 日记系统
- 📱 Mobile-style UI with virtual keyboard / 手机风格界面与虚拟键盘

---

## Tech Stack / 技术栈

- React
- Vite
- CSS

## Run Locally / 本地运行

```bash
# 第一步 克隆项目
git clone https://github.com/KIWI0912/starrymuse-box.git

# 第二步 进入文件夹
cd starrymuse-box

# 第三步 安装依赖
npm install

# 第四步 启动
npm run dev
```

启动后打开浏览器访问：
```
http://localhost:5173
```
