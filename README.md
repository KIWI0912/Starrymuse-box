# StarryMuse Box 🌟

> An interactive idol simulation game built with React.
> 一款基于 React 构建的偶像箱庭模拟游戏。

---

## Features / 功能特色

- 💬 Character chat system / 角色对话系统
- 📅 Daily schedule & activity choices / 每日日程与活动选择
- 🎒 Inventory and item collection / 道具收集与背包系统
- 📖 Diary system / 日记系统
- 📱 Mobile-style UI with virtual keyboard / 手机风格界面与虚拟键盘

---

## Tech Stack / 技术栈

- React
- Vite
- CSS

---

## Run Locally / 本地运行

```bash
# 安装依赖 Install dependencies
npm install

# 启动开发服务器 Start dev server
npm run dev
```
